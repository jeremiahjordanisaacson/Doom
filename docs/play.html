WASD to move, Q/E to strafe
Pure JavaScript Renderer: This is a hand-written JavaScript implementation of the DOOM BSP rendering engine for educational purposes. It demonstrates BSP tree traversal, wall projection, floor/ceiling rendering, and palette handling. Load a DOOM shareware WAD (DOOM1.WAD) for the full experience, or explore the built-in demo level.

Controls

WS -- Move Forward / Back
AD -- Turn Left / Right
QE -- Strafe Left / Right
Shift -- Run (2x speed)
Arrow Keys -- Move / Turn (alt)
F11 -- Toggle Fullscreen
