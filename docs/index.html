About the Project

The DOOM Multiplatform Mega-Repo is a comprehensive collection of DOOM source ports targeting every platform imaginable. From modern desktops to retro consoles, embedded systems to web browsers -- if it has a processor, it can probably run DOOM. Built on id Software's legendary GPL v2 open-source release, this repository organizes, maintains, and cross-compiles DOOM for 20+ platforms.
