# DOOM - Xbox Homebrew Port

**Status: Scaffold**

## Description

Original Xbox homebrew port of PrBoom using OpenXDK or nxdk (New Xbox Development Kit). Targets the original Xbox console (2001) with homebrew-enabled firmware. Leverages the Xbox's NV2A GPU for hardware-accelerated rendering.

## Target Hardware / OS

- Original Xbox (2001)
- Softmodded or hardmodded Xbox with replacement dashboard (XBMC, UnleashX, etc.)
- Xemu emulator for development testing

## Build Toolchain

- nxdk (New Xbox Development Kit) - recommended
  - OR OpenXDK (legacy, less maintained)
- nxdk includes: clang cross-compiler, Xbox libraries, packaging tools
- CMake 3.16+ or Make
- Optional: Xemu (Xbox emulator) for testing

## Build Instructions

```bash
# Clone nxdk
git clone --recursive https://github.com/XboxDev/nxdk.git
export NXDK_DIR=$(pwd)/nxdk

# Configure
cmake -B build \
  -DCMAKE_TOOLCHAIN_FILE=cmake/xbox-nxdk-toolchain.cmake

# Build
cmake --build build

# Output: default.xbe (Xbox executable)

# Test in Xemu
xemu -dvd_path build/doom.iso
```

> **Note:** Build instructions are preliminary and subject to change as the port is developed.

## Platform-Specific Notes

- The original Xbox has a 733 MHz Pentium III CPU and 64MB RAM; more than sufficient for DOOM.
- The NV2A GPU (based on GeForce 3) supports hardware-accelerated OpenGL-like rendering via nxdk's pbkit.
- Xbox controller input is mapped to standard DOOM bindings (analog sticks, triggers, buttons).
- The Xbox executable format (`.xbe`) is generated by nxdk's build tools.
- WAD files are bundled into the Xbox disc image or loaded from the hard drive.
- Audio uses the Xbox's MCPX APU for hardware sound mixing.
- Network play over Xbox system link (Ethernet) is theoretically possible.
- This port is for educational and preservation purposes. A modified Xbox console is required for real hardware testing.
